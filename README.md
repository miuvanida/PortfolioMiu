# Portofolio

Website statis (HTML, CSS, JS) tanpa build. Bisa langsung di-hosting.

## Cara edit
Buka `script.js`, ubah bagian `CONFIG` di paling atas (nama, about me, pengalaman, skill, link Behance, username GitHub, proyek desain, kontak). Repo GitHub tampil otomatis.

## Hosting gratis

**GitHub Pages**
1. Buat repo baru di GitHub, upload semua file ini.
2. Settings > Pages > Source: Deploy from a branch > pilih `main` dan folder `/ (root)`.
3. Tunggu 1-2 menit, link muncul di halaman yang sama.

**Netlify**
1. Buka app.netlify.com/drop
2. Seret folder ini ke halaman itu. Selesai.

**Vercel**
1. Upload folder ini ke GitHub, lalu di vercel.com pilih Add New > Project > Import repo itu.
2. Framework Preset: Other. Klik Deploy.
